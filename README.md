# CoreCourseGPA

Student recruiting hub mockup for NCAA core course GPA, eligibility, and recruiting prep.

**Live:** https://hewittfr.github.io/corecoursegpa/

## Stack

- React 19 + Vite + TypeScript
- Material UI
- Redux Toolkit
- Formik + Yup
- React Router

All data is dummy data for the student login experience.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).
